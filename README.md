## Data

Input data is in `data/`. Explore it and work from there. The interviewer will tell you when to unlock later stages.

```bash
python decrypt.py 2 <password>
python decrypt.py 3 <password>
```

**Bonus (only if the CSV is done):** a `GET` endpoint that accepts a user email and returns the documents that person can access. FastAPI or Flask is fine; you can serve from the output CSV or from the same transform in memory.
